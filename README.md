## 缺点和下单前必须确认的事

优惠结构偏碎。全站没有一个统一的折扣身份，优惠散在活动价、创作者码和首单券里，每样都有自己的门槛和上限。想算清最低价，得在结算页试。

首单券是二选一而且系统自动选。规则写在会员中心，结算时自动使用符合门槛的最高面额券，另一张失效。你想留着小额那张以后用，没有这个选项。

创作者码不是官方长期码。`Aniou0924` 来自第三方博主 11 月 4 日的活动帖，跟着这轮双11 走，活动结束后还能不能用没有保证。这也是为什么它不会出现在官网长期的优惠页上。

语言和平台支持不统一。同一批商品里，有的标注支持中文，有的明确写着不支持，比如 AirBuddy 和 CleanShot X。买之前看清楚，别等装完才发现界面全英文。

设备数买少了不好补。价格按设备数分档，事后想加一台通常要重新买一份授权，下单前数清楚你有几台机器。

关于店铺本身的独立评分，我没找到可核验的公开数据。能查到的第三方内容基本是针对具体软件的评测，不是对这家店的评分，所以这篇里不会出现“好评率”之类的数字。
